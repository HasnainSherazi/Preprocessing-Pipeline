# 🗄️ Large-Scale Image Preprocessing Pipeline

A high-performance image preprocessing pipeline built with Python and OpenCV, designed to handle datasets of **500,000+ images** efficiently for machine learning workflows.

---

## 📌 Overview

Training ML models requires clean, consistent data — but raw image datasets are often noisy, inconsistently sized, and unoptimized. This pipeline automates the full preprocessing workflow so you can go from raw images to ML-ready data at scale.

---

## ⚙️ Features

- ✅ Batch processing of 500,000+ images
- ✅ Resizing, normalization, and grayscale conversion
- ✅ Noise removal and contrast enhancement
- ✅ Automated directory management and output saving
- ✅ Progress tracking with logging

---

## 🛠️ Tech Stack

| Tool | Purpose |
|---|---|
| Python | Core scripting |
| OpenCV | Image processing operations |
| Jupyter Notebook | Experimentation and visualization |
| OS / Pathlib | File and directory management |

## 🚀 How to Run

```bash
# Clone the repository
git clone https://github.com/HasnainSherazi/Preprocessing-Pipeline.git
cd Preprocessing-Pipeline

# Install dependencies
pip install opencv-python jupyter

# Launch the notebook
jupyter notebook preprocessing-pipeline.ipynb
```
